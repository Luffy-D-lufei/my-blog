# vue-router的基本使用

  • 使用npm命令安装vue-router库

    npm install vue-router

  • 在src文件下创建router文件夹，然后在下面创建index.js文件

    import { createRouter,createWebHashHistory } from 'vue-router'

import Home from '../View/Home.vue'
import About from '../view/About.vue'

// 创建一个路由：映射关系
const router = createRouter({
    // 指定采用的模式
    history: createWebHashHistory(),
    // 映射关系
    routes:[
        { path:'/home',component:Home },
        { path:'/about',component:About }
    ]
})

export default router

  • 在main.js中使用

    import router from './router/index.js'

app.use(router)

  • 确定要替换的位置，使用router-view标签站位

  • 示例

    <template>
	<div class="app">
        <h2>App Content</h2>
        <div class="nav">
            // 以提供给我们直接路由跳转
            <router-link to="/home">首页</router-link>
            <router-link to="/about">关于</router-link>
    	</div>
        // 用于站位
        <router-view></router-view>
    </div>
</template>

# 默认的路由路径

  • 我们希望在默认情况下，进入网站就是展示页面的首页，但是路径中并没有和路由能匹配上的组件，所以我们需要重定向来解决默认进入页面就展示首页的组件。
  • 解决让路径默认跳转到首页，并且router-view渲染首页组件。
const couter = createRouter({
	history: createWebHashHistory(),
	routes = [
		{ path:'/',redirect:'/home' },     // 重定向到首页来解决
		{ path:'/home',component:Home },
		{ path:'/about'.component:About }
	]
})
  • 我们在routes中又配置了一个映射：
    • path配置的是根路径：/
    • redirect是重定向，也就是我们将根路径重定向到/home的路径下。

    # Vue3简介

    • 2020年9月18日，Vue.js发布了3.0版本，代号：One Piece（海贼王）
    • 经历了：4800+次提交、40+个RFC、600+次PR、300+贡献者
    • 官方发版地址：Announcing Vue 3.0 "One Piece" | The Vue Point (opens new window)

    # 性能的提升

    • 打包大小减少41%
    • 初次渲染快55%，更新渲染快133%
    • 内存减少54%

    # 源码升级

    • 使用Proxy代替defineProperty实现响应式。
    • 重写虚拟DOM的实现和Tree-Shaking。
